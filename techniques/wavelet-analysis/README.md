# Wavelet Analysis (Reference §13.19)

Time-frequency decomposition that resolves **local structure** in a non-stationary signal — unlike Fourier, which spreads a local feature across all frequencies. A wavelet basis is generated by translating and dilating a mother wavelet `ψ(t)`.

## Discrete Wavelet Transform (DWT)

Repeated filtering by a quadrature-mirror pair `(h, g)` (low-pass scaling filter + high-pass wavelet filter) followed by downsampling by 2. Result: an approximation at the coarsest scale plus a stack of **detail** coefficients at each resolution.

### Haar filter (simplest, fully explicit)

```
h = (1, 1) / √2                    Detail   = (x[2k] − x[2k+1]) / √2
g = (1, −1) / √2                   Approx   = (x[2k] + x[2k+1]) / √2
```

### Daubechies-4 (db4)

Four-tap orthonormal filter with two vanishing moments — the workhorse for smooth signals with occasional jumps.

## Wavelet denoising (Donoho-Johnstone 1994)

```
1. DWT of noisy signal.
2. Soft-threshold each detail coefficient:  d' = sign(d) max(|d| − λ, 0)
3. Inverse DWT.
```

**Universal threshold** `λ = σ √(2 log N)` where `σ` is estimated from the level-1 detail via the MAD:

```
σ̂ = median(|d_1|) / 0.6745
```

Optimal in the minimax sense over a wide class of function classes (Besov, bounded variation).

## Files

- `python/wavelet_analysis.py` — from-scratch Haar and Daubechies-4 filter banks, multi-level DWT / IDWT, and universal-threshold denoising. Perfect reconstruction (max error 1.5 × 10⁻¹⁵) and 85% MSE reduction on a sinusoid + step signal at σ = 0.3 noise.
- `r/wavelet_analysis.R` — `wavelets::dwt` and `wavethresh::wd` + `threshold()` for the standard R interface.

## Applications

- Denoising signals with sharp features (edges, jumps) that Fourier smoothes out.
- Compression (JPEG-2000 uses wavelet-based coding).
- EEG / ECG / seismic feature extraction.
- Multiresolution regression, functional-data analysis.

## Beyond DWT

- **Continuous wavelet transform (CWT)** — no downsampling; produces a 2-D time-frequency scaleogram. Useful for visualization but redundant.
- **Wavelet packet transform** — recursively decompose the detail channels too, giving a richer frequency partition.
- **Maximal overlap DWT (MODWT)** — shift-invariant version for time-series analysis.

## Assumptions

- **Signal length**: fastest with `N = 2^K`; the code here pads to the next power of two, but decimation at each level loses samples if `N` is not a power of two.
- **Boundary handling**: circular here; alternatives include zero-padding, symmetric extension, or periodic wrap. Circular can create artifacts on non-periodic signals.
