# β-VAE for Disentanglement (Reference §47.288)

Higgins et al (2017). Modify the VAE ELBO to encourage
disentangled latent factors:

```
ELBO_β = E_q[log p(x | z)] − β · KL(q(z | x) ‖ p(z))
```

with `β > 1`. Trades reconstruction fidelity for independent
latent axes. Standard for representation-learning benchmarks
(dSprites, 3D shapes, MPI3D).

## Files

- `python/beta_vae_disentangle.py` — β-scaled ELBO with a
  toy 2-D dataset generated by two independent factors.
  Illustrates ELBO_β across β = 1, 4, 16 and toy latent
  correlation. Real training-run pipeline recipe (MIG / DCI /
  FactorVAE scoring, reconstruction fidelity trade-off)
  provided as pseudo-code.
- `r/beta_vae_disentangle.R` — reticulate + PyTorch VAE (R);
  google-research/disentanglement_lib, Pyro,
  from-scratch (Python).

## When to use

- **Learning disentangled representations** for downstream
  interpretable factors (pose, lighting, object identity).
- **Data compression + interpretability** trade-off.
- **Comparing generative model latent structures** across
  β values.

## When NOT to use

- **Fidelity-critical generation** — high β sacrifices
  reconstruction; use β=1 or vanilla VAE.
- **Small dataset** — the β penalty needs many samples to
  learn independent axes.
- **Non-continuous factors** — discrete factors need
  categorical variational or β-TCVAE variants.

## Assumptions & caveats

- **β choice** — 4, 16, 64 typically; larger β → more
  disentangled but blurrier reconstructions.
- **β-TCVAE, FactorVAE** — variants that penalise
  Total Correlation explicitly for better disentanglement.
- **Metrics** — MIG (Mutual Information Gap), DCI, FactorVAE,
  and SAP are the standard scores.
- **Rotation of latents** — a learned latent space can be
  disentangled up to an orthogonal rotation; identifiability
  needs weak supervision (Locatello 2019).
